Chave gratuita do YouTube

Para achar transmissões ao vivo perto de cada lugar, o mapa usa a API oficial do YouTube. A chave é gratuita e não pede cartão:

  1. Entre em console.cloud.google.com com sua conta Google e crie um projeto (nome: CameraWeb).
  2. Abra YouTube Data API v3 e clique em Ativar.
  3. Vá em Credenciais → Criar credenciais → Chave de API.
  4. Copie a chave (começa com AIza) e cole abaixo. Ela fica salva no arquivo chave-youtube.txt.

Token gratuito da SPTrans (ônibus)

Com ele, o mapa recebe a posição de todos os ônibus de São Paulo a cada 30 segundos e mostra onde eles estão parados.

  1. Entre em sptrans.com.br/desenvolvedores e cadastre-se.
  2. Em Meus Aplicativos, clique em Adicionar novo aplicativo (nome: CameraWeb; descrição: mapa pessoal).
  3. Copie o token gerado e cole abaixo. Fica salvo no arquivo chave-sptrans.txt.

Chave gratuita para navios

As posições dos navios vêm da AISStream.io, uma rede aberta de receptores AIS. A chave é gratuita:

  1. Entre em aisstream.io/account e faça login.
  2. Na página da conta (Account), crie uma chave de API.
  3. Copie e cole abaixo (ela só aparece uma vez no site). Fica salva no arquivo chave-aisstream.txt.

Chave gratuita da Windy

As câmeras vêm da base pública da Windy (dezenas de milhares no mundo todo). Para usar, é preciso uma chave gratuita:

  1. Acesse api.windy.com/keys e crie uma conta.
  2. Crie uma chave do tipo Webcams API (plano Free).
  3. Cole a chave abaixo. Ela fica guardada só neste navegador.
